# Maturity and hardening checklist

A capability is not “done” because code exists.

- **Contract:** schema, invariants, versioning, failure modes, rights and threats.
- **Correctness:** unit, property, metamorphic, malicious and golden fixtures.
- **Scientific validity:** construct coverage, human alignment, uncertainty,
  subgroup/task effects and sensitivity analyses.
- **Reproducibility:** immutable inputs, environment identity, hashes and rerun.
- **Security:** bounded resources, isolation, least privilege and no arbitrary code.
- **Operations:** observability, cost caps, retries, resumability and rollback.
- **Governance:** decision record, issue/track synchronization, release notes and
  deprecation/bridge policy.
- **Sustainability:** dependency budget, maintenance owner, scheduled drift audit
  and archive path.
