# V1 pilot amendment 002: execution and calibration hardening

This before-data, non-task-affecting amendment hardens campaign execution, evaluator-input safety, design assurance, protocol fixity, and calibration operations. It does not change the committed candidate task set.

The campaign retains terminal failures and requires explicit budget and qualification gates. Automatic judges receive only canonical rendered evidence through the judge firewall; visible evaluator-directed instructions are quarantined and remain in the denominator. Design reporting retains clustered-replicate uncertainty, while calibration stopping requires the prespecified workload, validity, calibration, and repeat-consistency gates.

Primary reporting separates judge-firewall quarantines. The sensitivity analysis reports conjunctive failures without changing the candidate task commitment. No empirical outcome had been observed when this amendment was recorded.
