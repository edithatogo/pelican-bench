# Longitudinal image and SVG analysis

For every rights-cleared artifact, retain the original bytes, canonical render,
renderer version and extraction log. Suggested quantitative features include:

- Canvas dimensions, viewBox, element counts, path commands, transforms, groups,
  reusable symbols, text, embedded images, external references and file size.
- Connected components, wheel count/circularity/alignment, frame graph, pedal and
  handlebar candidates, animal/object bounding boxes and overlap.
- Pelican keypoints and features: bill-to-head ratio, pouch evidence, wing/body,
  leg/foot geometry and species confusions.
- Interface evidence: body support, control contact, feet/pedals, centre of mass,
  occlusion ordering and semantic role.
- Blind captions, atomic question responses and human pairwise outcomes.
- Artifact editability and local-edit preservation.

Time-series plots must display missingness and uncertainty. Renderer, scorer and
annotation revisions are covariates, not invisible preprocessing details.
