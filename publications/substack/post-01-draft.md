# The joke that became a benchmark

A pelican riding a bicycle is funny because it is immediately understandable and mechanically absurd. That makes failure legible. It also makes the prompt unusually useful: an image can contain a convincing pelican and a convincing bicycle while still failing to show the first riding the second.

PelicanBench preserves the public prompt as a historical anchor, but the scientific question is broader. Can a system construct the right entities, parts, and relations reliably? Can it explain and repair a failure? Can an agent improve through a visible sequence rather than hide every unsuccessful attempt? The first release builds the contracts needed to ask those questions without pretending that a single scalar or a single judge supplies the answer.
