# Security policy

Report vulnerabilities privately through GitHub’s security-advisory mechanism. Do not attach malicious SVGs that could execute in a browser to public issues.

The threat model covers XML entity expansion, scripts, foreign objects, external references, CSS and filter URLs, path-complexity denial of service, metadata prompt injection, judge-targeting visible or hidden text, unsafe model repository code and sealed-task disclosure. Canonical evaluation parses bounded source, renders in an isolated container and records the renderer digest.

Supported security fixes target the latest alpha and subsequent stable releases. Rights or privacy issues may also be reported privately.
